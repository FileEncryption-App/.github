## 🚀 Overview
File Encryption for Windows is a security app that helps you keep your own documents, photos, and sensitive files private. It applies strong, industry-standard AES encryption and locks each file or folder behind a password that you choose, so anyone without that password cannot read the contents. Whether you store financial records, work documents, or personal data, File Encryption gives you a straightforward way to protect what belongs to you directly on your PC.

## ✨ Features
- **Strong AES encryption** — Secures your files with proven, industry-standard AES so your data stays unreadable without your password.
- **Password protection** — Locks any file or folder behind a password you set, keeping prying eyes out of your personal data.
- **Folder encryption** — Encrypt an entire folder at once, ideal for organizing and protecting whole projects or archives.
- **Local, on-device processing** — Encrypts your files right on your Windows PC, so your data never has to leave your machine.
- **Simple, focused interface** — Select a file, choose a password, and encrypt in a few clicks — no technical background required.

## 🎯 Getting Started
1. Open File Encryption on your Windows PC.
2. Select the file or folder you want to secure.
3. Choose a strong password and confirm it — this is the key to your data, so keep it safe.
4. Start the encryption and wait for it to finish.
5. To open your data later, select the encrypted item and enter your password to decrypt it.
